# فیلترشکن | پنل مدیریت

پنل مدیریت فارسی، راست‌چین و واکنش‌گرا با React و TypeScript در کلاینت و Express در سرور.

## اجرا

```bash
npm install
npm run dev
```

وب‌اپ در `http://localhost:5173` و API در `http://localhost:3001` اجرا می‌شود.

## ورود پیش‌فرض

- نام کاربری: `ehsan`
- رمز عبور: `232111Eee@`

برای تغییر اعتبار ورود، مقادیر `ADMIN_USERNAME` و `ADMIN_PASSWORD` را در محیط اجرا تنظیم کنید. نمونهٔ متغیرها در `.env.example` آمده است.

## PostgreSQL

سرور برای اجرا به PostgreSQL نیاز دارد. مقدار `DATABASE_URL` را در محیط اجرا تنظیم کنید؛ سرور در اولین راه‌اندازی جدول‌های مدیران، نشست‌ها، کاربران و پیام‌های چت را می‌سازد و کاربران نمونه را اضافه می‌کند. رمز عبور مدیر هنگام ساخت اولیه ذخیره می‌شود. برای دیتابیس‌های ابری که TLS نیاز دارند، `DATABASE_SSL=true` تنظیم کنید. در Vercel مقدارهای `DATABASE_URL` و در صورت نیاز `DATABASE_SSL` را در Project Settings → Environment Variables وارد کنید.

## بخش‌ها

- داشبورد با آمار، نمودار و فهرست کاربران اخیر
- فهرست و جست‌وجوی کاربران
- صفحهٔ اشتراک‌ها
- گفت‌وگوی پشتیبانی

ورود از API سمت سرور بررسی می‌شود و مسیرهای API پس از ورود به توکن نشست نیاز دارند. مدیر، نشست‌ها، کاربران و پیام‌های چت در PostgreSQL نگهداری می‌شوند. داده‌های اشتراک و آمار داشبورد فعلاً نمونه‌ای هستند.
